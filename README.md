# Teh Dandang — Sales Mobile Mockup

Mockup front-end mobile-first untuk alur Sales: Dashboard, Jadwal Kunjungan, Daftar Outlet, Check-in, dan Hasil Kunjungan.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser modern (Chrome/Edge).
3. Tidak membutuhkan instalasi package, backend, atau koneksi API.

## Interaksi demo
- Navigasi bawah dan menu drawer.
- Filter jadwal dan outlet, pencarian outlet.
- Pilih outlet dan mulai check-in simulasi.
- Isi lalu simpan hasil kunjungan atau draft.
- Seluruh data contoh berada di `js/data.js`.

## Batasan
- Data, lokasi, waktu, dan status adalah dummy/simulasi.
- Tidak menggunakan GPS perangkat, SAP, API, atau penyimpanan server.
- Warna dan struktur visual terinspirasi dari referensi yang diberikan; aset/logo resmi belum disertakan.
